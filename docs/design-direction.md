# 视觉方向：潮汐图册（Tide Atlas）

## 页面职责

- 主题：AI 创作者作品集「比特海盗的码头」。
- 受众：喜欢动手做 AI 作品、希望被看见的创作者，以及从小红书来到这里的浏览者。
- 首页唯一任务：让访客迅速看到真实作品，并愿意打开一个作品或投递自己的作品。

## 设计选择

不把页面做成常见的“黑底霓虹赛博海盗”。码头像一张持续更新的航海图册：深蓝墨水是底，海雾色是留白，铜绿和灯塔橘只用于方向与行动。

### Token

| 名称 | 值 | 用途 |
| --- | --- | --- |
| 深海墨 | `#082B36` | 主文字、深色区域 |
| 海图纸 | `#E7E6D7` | 页面底色 |
| 雾蓝 | `#9CB9B6` | 次级信息、分隔 |
| 铜绿 | `#1D7B72` | 筛选、链接、交互 |
| 灯火橘 | `#E57A38` | 主行动与关键标记 |
| 红珊瑚 | `#B64F46` | 驳回和危险提示 |

### 排版

- 展示字：`LXGW WenKai`，用于站名和作品标题，像航海日志的笔触但保持中文可读性。
- 正文：`Noto Sans SC`，保证长文本与移动端清晰。
- 数据/标签：`IBM Plex Mono`，让时间、坐标和分类像图例。

### 结构与标志性元素

首页首屏不是空泛口号，而是一条“潮汐航线”：根据当日时间变化的细线从码头标题延伸到最新作品。它承担“新作品正在靠岸”的真实状态；其余区域保持克制。

```
┌──────────────────────────────────────┐
│ 比特海盗的码头         [投递作品 →]   │
│ 一张潮汐航线 ───────── 最新靠岸        │
│ 作品网格 / 可按航线标签筛选             │
└──────────────────────────────────────┘
```

### 动效与可访问性

- 首屏潮汐线仅一次缓慢绘制；卡片悬停轻微上浮。
- `prefers-reduced-motion` 下取消动画。
- 所有交互元素提供清晰焦点，颜色不作为唯一信息载体。
