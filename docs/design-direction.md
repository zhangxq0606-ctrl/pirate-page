# 视觉方向：数字航海日志（Digital Ship's Log）

## 页面职责

- 主题：AI 创作者作品集「比特海盗的码头」。
- 受众：喜欢动手做 AI 作品、希望被看见的创作者，以及从小红书来到这里的浏览者。
- 首页唯一任务：让访客迅速看到真实作品，并愿意打开一个作品或投递自己的作品。

## 设计选择

不把页面做成常见的“黑底霓虹赛博海盗”，也不再把海盗只当成颜色和文案。码头是一张被船长长期使用的数字航海日志：海图、航线、旗标、抵港清单、潮痕共同构成信息结构。海盗精神不是扮装，而是把未知带回岸上的探索、协作与分享。

### Token

| 名称 | 值 | 用途 |
| --- | --- | --- |
| 船舱深海 | `#092C35` | 主文字、船壳、深色区 |
| 海图帆布 | `#DCE0C7` | 页面底色 |
| 盐雾青 | `#80A9A4` | 次级信息、航线 |
| 航标金 | `#D99037` | 旗标、主行动、坐标 |
| 锈红 | `#A74C3D` | 印章、驳回与风险 |
| 浪沫白 | `#F5F1DE` | 表面、正文对比 |

### 排版

- 展示字：`LXGW WenKai`，用于站名和作品标题，像航海日志的笔触但保持中文可读性。
- 正文：`Noto Sans SC`，保证长文本与移动端清晰。
- 数据/标签：`IBM Plex Mono`，让时间、坐标和分类像图例。

### 结构与标志性元素

首页首屏不是空泛口号，而是一张“正在抵港的航海图”：虚线航路穿过潮线，唯一的金色旗标标记最新作品的靠港坐标。它把每次发布变成一次抵港，其余区域保持克制。

```
┌──────────────────────────────────────┐
│ 船长日志 / 创作码头        [送进港 →]  │
│ 航海图、虚线航路、靠港旗标              │
│ 抵港清单 / 可按货物类型筛选             │
└──────────────────────────────────────┘
```

### 动效与可访问性

- 首屏潮汐线仅一次缓慢绘制；卡片悬停轻微上浮。
- `prefers-reduced-motion` 下取消动画。
- 所有交互元素提供清晰焦点，颜色不作为唯一信息载体。
